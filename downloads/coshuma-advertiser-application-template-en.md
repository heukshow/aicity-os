# COSHUMA Advertiser Application Template

Use this template to prepare a Sponsored text-card application. It does not place an order, reserve a position, submit an application or confirm a payment.

Start at [coshuma.com/advertise.html](https://coshuma.com/advertise.html). The page shows available choices and the application or payment steps currently offered. A COSHUMA account is not required. If online intake is unavailable, copy the prepared application text, paste it into an email to support@coshuma.com, and send it. Preparing or copying text is not a successful submission.

## 1. Application information

Copy the information accurately. If an application reference has already been issued, use it when following up rather than creating a duplicate request.

```text
Existing COSHUMA application or order reference, if already issued:

1. Company name:
   Maximum 120 characters.

2. Tool or product name:
   Maximum 120 characters. Use the actual advertised product name.

3. Contact email:
   Maximum 254 characters.

4. Requested placement:
   [ ] Tool Page Sponsored
   [ ] Featured Buyer Guide Placement
   [ ] Comparison Premium

5. Requested duration:
   [ ] 7 days
   [ ] 30 days
   [ ] 90 days
   For 180 days or longer, contact support separately.

6. Target COSHUMA page:
   Select the exact page from the choices currently offered.

7. Destination URL:
   HTTPS address on a public domain. Maximum 1,000 characters.

8. Headline:
   5-80 characters.

9. Description:
   20-240 characters.

10. CTA button text:
    2-30 characters. Match the action available at the destination.

11. Requested start date, optional:
    YYYY-MM-DD. This is a preference, not a confirmed schedule.

12. Accuracy and rights confirmation:
    [ ] I confirm that the submitted information is accurate and that
        I have the right to promote the product and use this content.
```

No logo, banner image or video is required. Do not send passwords, card details, verification codes, secret keys or unnecessary personal information.

## 3. Prepare evidence for review

Keep the following information ready if requested. This is preparation guidance, not a claim that the online form has separate fields for every item.

### Tool Page Sponsored

```text
Why is the product relevant to the selected tool page?

Is it an alternative or a complement?

Which customers or tasks make it worth considering?

Supporting evidence for material claims or comparisons:
```

### Featured Buyer Guide Placement

```text
Why does the product fit this buyer guide or category?

Two or three specific, supportable benefits:

Ideal customer and task in one sentence:

Material pricing, plan, trial or usage conditions:
```

### Comparison Premium

```text
Which products are compared on the selected page?

Why is your product a relevant third option?

Which customer conditions make it suitable?

Supporting evidence for any direct comparison:
```

All advertising is labeled Sponsored. It does not buy an editorial ranking, score or recommendation, and it does not guarantee visits, clicks, leads, sales or revenue.

## 4. Payment matching, only if support requests it

The applying company, advertised product and payer name may differ. An agency can pay for another company's product. Do not rename a PayPal account to match the company or product.

Use the COSHUMA order reference supplied to you. The payer name is only a matching aid; actual payment verification depends on the order and PayPal records. Never invent an order or transaction reference.

```text
COSHUMA application or order reference:

Applying company:

Advertised tool or product:

Payer display name shown on PayPal, if needed for matching:

Available PayPal transaction reference, if requested:
Reference only. Do not include login or card information.

Brief business explanation if the payer differs, optional:
For example, an agency paying for its client's product.
```

A message or screenshot saying payment is complete does not activate an ad. Payment verification, creative approval and actual publication are separate stages. Use only the payment options currently offered on the advertising application page.

## 5. Cancellation, change or refund request

Contact [support@coshuma.com](mailto:support@coshuma.com) with the reference and a short explanation. Do not include sensitive payment credentials.

```text
COSHUMA application or order reference:

Applying company and advertised product:

Request type:
  [ ] Cancel before publication
  [ ] Purchased placement cannot be provided
  [ ] Request review of an undelivered period after go-live
  [ ] Request a creative or destination change
  [ ] Request an extension

Brief explanation:
```

Before go-live, or if COSHUMA cannot provide the purchased placement, you may request review and processing of a full refund. After the campaign starts, adjustment for an undelivered period is reviewed individually. Statutory rights are not limited. A request does not mean a refund has already been issued or automatically approved.

See [the cancellation and refund policy](https://coshuma.com/sponsorship.html#refunds). Extensions require a confirmed new period and available inventory.
