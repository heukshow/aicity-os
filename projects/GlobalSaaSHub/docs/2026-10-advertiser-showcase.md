# Advertiser showcase and inquiry path — 5 October 2026

The owner asked to make advertising on COSHUMA appealing after the three unpaid house advertisements went live. This change improves the existing /advertise.html and adds a restrained advertiser link to those three house cards. It does not publish the proposed /advertising/ page or the review PDFs, accept a paid image booking, enable checkout, create a payment or claim advertiser revenue.

## Scope and rationale
Observed issue: the house cards had no path for an interested software company to explore a placement, while the existing advertising page asked for a full creative brief before a simple inquiry. Existing house screenshots, catalogue rates and existing mail contact are sufficient; no new provider or credential is needed.

The change uses actual house-ad screenshots from the 05:10 KST live verification of PR #1023, presents three relevant contexts, shows planning rates from the existing catalogue, and lets the visitor prepare an email from a product name and HTTPS website. Placement and duration are optional choices. Nothing is automatically submitted or persisted. The screenshots are not client endorsements or evidence of paid-ad performance. Mobile screenshots are emulation.

Existing text-application markup is retained only inside an inert HTML template for compatibility and rollback. It is not live document content. The legacy sales script exits before initialization in inquiry mode. Both barriers prevent a stale API configuration from enabling checkout through this page. Financial API and Worker settings are unchanged.
