# EVAL-001 standardized hands-on evaluation feasibility — 2026-10-03

## Decision
NO-GO for implementation or publication during the fixed 2026-09-28 through 2026-10-04 measurement window.

Conditional GO for one unpublished pilot after 2026-10-07 only if existing authorized access supports equivalent no-cost runs for both products. Otherwise remain NO-GO.

## Candidate pilot
Jotform vs Tally form builders. Candidate only; no hands-on run has been performed.

## Protocol
1. Use one identical synthetic lead/RSVP-form brief for both products.
2. Hold fields, sample values, device class, language, and equivalent tier constant.
3. Record product, checked date, tier, visible version/model if shown, completion state, substantive correction steps, visible limitations, sharing/export friction, and retained final-result evidence.
4. Keep vendor-confirmed facts, COSHUMA direct observations, and unknown/not-tested separate.
5. Stop when conditions are no longer equivalent or a protected user gate is reached.
6. Use synthetic, non-personal data only.
7. Do not publish hands-on wording unless both comparable runs finish and evidence artifacts are retained.
8. Retest only after material tier/product/workflow change or stale-evidence review; do not continuously rerun.

## Evidence reviewed
- Current main methodology page: source-backed facts, supplier confirmation, sponsorship separation.
- Current main operations registry: EVAL-001 remains evidence_validated and paper-only.
- G2 announcement dated 2026-09-22: its Agent Evaluations public beta describes live agents in a category receiving identical work and resources and being assessed on observed results. This supports controlled same-task comparison as a useful method but does not authorize copying G2 scoring or imply COSHUMA has run tests.

No public page, ranking, score, CTA, affiliate state, analytics event, paid service, or deployment change is authorized by this feasibility decision.
