# COSHUMA public brand policy

- Customer-facing brand name: `COSHUMA`.
- Legacy customer-facing names such as `GlobalSaaSHub`, `Global SaaS Hub`, and `Global AI SaaS Decision Platform` must not appear in production HTML.
- Internal repository paths may retain the historical `projects/GlobalSaaSHub/` directory name when renaming would create unnecessary deployment risk.
- Production tests must block reintroduction of the legacy customer-facing names.
