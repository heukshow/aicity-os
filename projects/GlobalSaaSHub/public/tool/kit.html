What you get on the $0 plan

✓ Up to 10,000 subscribers
✓ Unlimited forms and landing pages
✓ Unlimited email broadcasts
✓ Audience tagging and segmentation
✓ Digital products and subscriptions
✓ API access

The main upgrade trigger is automation depth. Kit's current help documentation places visual automations, email sequences, automation rules and several advanced recommendation features on paid plans.

A good fit when

  • • You want to start a newsletter without paying before the audience grows.
  • • You sell digital products, subscriptions or a paid newsletter from the same creator stack.
  • • You expect to use tags, segments, sequences and visual automations as the list matures.

Compare alternatives first when

  • • Your priority is the lowest paid entry price rather than a creator-focused ecosystem.
  • • Your workflow depends more on ecommerce or enterprise CRM features than newsletters and creator automation.
  • • You need paid automations immediately and want to compare subscriber-based pricing before migrating.

What to test before upgrading

Start with one real newsletter workflow: create a form or landing page, import or collect subscribers, send broadcasts, tag readers and test a product or subscription offer. Upgrade only if sequences, visual automations or the paid-plan analytics solve a real bottleneck.
